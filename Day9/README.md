# Day 9 – Processed E-commerce Dataset

This project uses **Python and Pandas** to process e-commerce data.

### Files

* `Day9_Ecommerce_Analysis.ipynb` – Analysis notebook
* `Day9_Orders.csv` – Orders dataset
* `Day9_Customers.csv` – Customers dataset
* `Day9_Products.csv` – Products dataset
* `Day9_Processed_Ecommerce_Dataset.csv` – Final processed dataset

### Operations Performed

* Loaded CSV files using Pandas
* Used `merge()` and `concat()`
* Used `apply()` for data transformation
* Performed DateTime operations
* Cleaned and organized the data
* Exported the processed dataset as CSV
